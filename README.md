#Proyecto Minimarket
El *Proyecto Minimarket* y *Carrito Roxy* es una propuesta comercial conjunta estructurada para capturar dos mercados clave: el consumo familiar estable y la compra por impulso. 

Esta colaboración une la infraestructura de un punto de venta fijo con la flexibilidad de una unidad móvil para optimizar recursos logísticos y de marketing.


**El Minimarket**: Registro de inventario para mantener el control de stock y venta de los productos del Minimarket



**El Carrito Roxy**: Una unidad de negocio dedicada a la venta en base a la selección de productos
